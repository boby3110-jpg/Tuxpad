# ---------------------------------------------------------------------------
# PySide6 6.12.0 は Python 3.11 で使えない（2026-10-11（72 回目）で判明）
#
#   PySide6 6.12.0 は **戻り値の無い（void の）メソッドを呼ぶたびに
#   `None` の参照を 1 つ取りこぼす**（shiboken の refcount バグ）。
#   `None` が不滅（immortal）になった Python 3.12 以降では無害だが、
#   **Python 3.11 では参照数が 0 まで減り、
#   「Fatal Python error: none_dealloc: deallocating None」で
#   プロセスごと落ちる**（10 万回ほどの Qt 呼び出しで到達する＝
#   編集中に突然終わる＝未保存の本文が消える）。
#   手元で確かめた範囲: 6.11.2 は Python 3.11 でも問題なし、
#   6.12.0 のみ該当。見張りは tests/test_pyside_runtime_sanity.py。
#   6.12.1 以降で直ったら、下の除外に上限を足すのではなく
#   実際に確かめてから緩めること。
# ---------------------------------------------------------------------------
PySide6>=6.6; python_version >= "3.12"
PySide6>=6.6,!=6.12.0; python_version < "3.12"
charset-normalizer>=3.3
